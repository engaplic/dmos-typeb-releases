# DMOS Type B - pacotes de atualizacao

Pacotes de atualizacao assinados (`.dtb`) do DMOS Type B, baixados pela tela
**Sistema** do proprio equipamento. Cada release traz o pacote e as notas da
versao.

O equipamento so instala pacote com assinatura valida da Datacom; um arquivo
alterado ou de outra origem e recusado. Para locais sem internet, baixe o
`.dtb` da release e use "Enviar pacote" na tela Sistema.

Este repositorio nao contem codigo-fonte.
